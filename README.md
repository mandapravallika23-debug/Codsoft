# To-Do List Application

## Description
This is a simple To-Do List Application developed using Python. The application helps users manage and organize their daily tasks efficiently.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- User-friendly interface

## Technologies Used
- Python

## How to Run
1. Install Python on your system.
2. Download the project files.
3. Open the project in Visual Studio Code.
4. Run the Python file using:

```bash
python todolist.py
